# AI Resume Analyzer

## Project Overview
AI Resume Analyzer is a web-based application designed to automate the process of resume screening using Artificial Intelligence and Natural Language Processing (NLP). The system analyzes resumes, extracts relevant details, and matches them with job descriptions to assist recruiters in efficient candidate shortlisting.

---

## Features
- Resume upload and parsing  
- Skill extraction using NLP  
- Job description matching  
- Resume scoring and analysis  
- User-friendly and responsive UI  
- Clean and professional dashboard  

---

## Technologies Used
- React  
- Vite  
- TypeScript  
- Tailwind CSS  
- shadcn/ui  
- Framer Motion
